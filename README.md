# InnoHub Admin Dashboard - 
InnoHub İnnovasiya Mərkəzi üçün hazırlanmış tam funksional daxili idarəetmə sistemi. Administratorlara platformadakı bütün məzmunu idarə etmək imkanı verir: kurslar, tədbirlər, hakatonlar, layihələr, bloqlar, müəllimlər, məzunlar, tərəfdaşlar, vakansiyalar, FAQ və ana səhifə karusel bölmələri. Dashboard tam CRUD əməliyyatlarını, istifadəçi müraciətləri və qeydiyyatların idarəsini, sürüklə-burax (drag-and-drop) məzmun sıralamasını və təhlükəsiz JWT əsaslı autentifikasiyanı dəstəkləyir. Layihə miqyaslana bilən arxitektura, təmiz kod strukturu, formaların doğrulanması və rahat istifadəçi təcrübəsi üzərində qurulub.
